# Day-14-Rest-Day

Rest day for the **Ai-Ml-Month-01-Python-and-Maths** learning journey.

This folder marks Day 14 — a scheduled break after an intensive week of learning (Day 7 through Day 13). Use this day to rest, review your notes, and let the concepts sink in before continuing with the next module.

---

## Week in Review: Day 7 – Day 13

Below is a summary of what was built and learned during Days 7–13 of the AI/ML Month 01 (Python and Maths) track.

### Day 7 — Python Functions & Modules
- **Built:** Reusable Python scripts using functions, default arguments, `*args`/`**kwargs`, and lambda expressions.
- **Learned:** How to structure code with functions, scope (local vs global), importing built-in and custom modules, and the Python standard library.

### Day 8 — Object-Oriented Programming (OOP)
- **Built:** Small Python projects using classes and objects (e.g., a simple class hierarchy for ML data structures).
- **Learned:** Classes, objects, constructors (`__init__`), instance vs class attributes, methods, inheritance, method overriding, and encapsulation.

### Day 9 — File I/O & Error Handling
- **Built:** Scripts that read/write CSV and text files, parse data, and gracefully handle exceptions.
- **Learned:** Opening files with `with` context managers, reading/writing text and CSV data, `try`/`except`/`finally`, custom exceptions, and logging basics.

### Day 10 — NumPy Vectorization Benchmark
- **Built:** `Day-10-Numpy-Vectorization-Benchmark` — a reproducible benchmark comparing native Python list operations against NumPy vectorized array operations on one million integers.
- **Learned:** NumPy array creation, vectorized arithmetic, boolean masking, `time.perf_counter()` benchmarking, and why vectorization beats Python loops for numerical workloads.

### Day 11 — Data Visualization with Matplotlib
- **Built:** Line plots, bar charts, histograms, and scatter plots to visualize datasets and benchmark results.
- **Learned:** Matplotlib `pyplot` API, figure/axes objects, styling, labels, legends, saving figures, and visualizing NumPy arrays.

### Day 12 — Linear Algebra for Machine Learning
- **Built:** Python/NumPy implementations of vector addition, scalar multiplication, dot products, matrix multiplication, and transpose operations.
- **Learned:** Vectors, matrices, matrix shapes, dot product, matrix multiplication, identity/inverse matrices (conceptually), and how linear algebra underpins ML algorithms.

### Day 13 — Calculus Basics for ML
- **Built:** Numerical derivative calculations using finite differences and simple gradient computations in Python.
- **Learned:** Limits, derivatives, slope/rate of change, partial derivatives, gradients, and how gradients are used in optimization (e.g., gradient descent).
